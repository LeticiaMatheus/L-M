CONVITE DE CASAMENTO — LETICIA & MATHEUS

Arquivos do site:
- index.html
- presentes.html
- admin.html
- css/style.css
- js/config.js
- js/countdown.js
- js/presentes.js
- js/admin.js

COMO USAR
1. Envie todos esses arquivos para o seu repositório do GitHub Pages, mantendo as pastas css e js.
2. Abra o site normalmente em index.html.
3. A lista de presentes usa o Google Apps Script já configurado.
4. Para o painel, abra admin.html e digite o mesmo token que está no Code.gs do Apps Script.
5. Se o navegador mostrar uma versão antiga, use Ctrl+F5.

IMPORTANTE
- Não coloque o Code.gs com o token privado em um repositório público.
- O arquivo js/config.js não contém o token do administrador.
- A aba da planilha deve continuar sendo "Presentes".
